## 1. 为什么需要 Cache

CPU 执行速度通常远快于主存访问速度。Cache 是位于处理器和更低层存储之间的高速、小容量存储，用来保存近期可能使用的数据和指令，降低平均访存时间。

现代处理器通常有 L1、L2、L3 多级 Cache。一般越靠近 CPU，容量越小、速度越快；具体结构由处理器实现决定。

## 2. 命中与未命中

- Cache 命中：所需数据已经在 Cache 中，可快速读取。
- Cache 未命中：需要从更低层级取回数据，并通常按 Cache line 装入 Cache。

Cache 的价值取决于命中率和不同层级访问代价，而不是“所有数据都复制到更快内存”。

## 3. 两种局部性

### 时间局部性

刚访问的数据或指令在不久后可能再次访问。

```python
for _ in range(1_000_000):
    total += value
```

循环中反复访问 `value` 和循环指令。

### 空间局部性

访问某地址后，附近地址的数据或指令可能很快被访问。

```python
for value in array:
    total += value
```

顺序访问连续数组通常比随机跳转更符合空间局部性。

## 4. 数组与链表的联系

数组连续存储，顺序遍历通常有较好的空间局部性。链表结点可能分散，访问需要追踪指针，缓存表现通常较差。因此算法复杂度相同不代表实际运行时间相同。

## 5. AI 和数值计算

- NumPy 数组通常使用连续或规则布局，更利于批处理、向量化和缓存。
- Python 对象包含额外元数据，多个对象之间还可能通过指针间接访问。
- embedding、矩阵计算和模型推理性能还受 GPU 显存、带宽、批大小和底层算子影响，不能只用 CPU Cache 解释。

## 易错点

1. Cache 不是普通业务缓存 Redis 的同义词；这里讨论的是计算机存储层次。
2. “Cache 更快”不是完整解释，核心是用局部性提高命中率并降低平均访问时间。
3. 时间局部性和空间局部性不要混淆。
4. 大 O 复杂度相同的程序可能因缓存行为不同而性能差异很大。

## 面试表达

Cache 利用程序的时间局部性和空间局部性，把近期使用或附近的数据和指令保存在比主存更快的存储中，从而减少 CPU 访问主存的次数并降低平均访存时间。时间局部性是近期访问的数据可能很快再次访问，空间局部性是当前地址附近的数据可能很快被访问。
