## 1. 对象、变量名和名称绑定

Python 中数据以对象存在。变量名不是装值的固定内存盒子，更严谨地说，变量名与对象建立绑定关系。

```python
a = [1, 2]
b = a
```

`a` 和 `b` 是两个名称，绑定到同一个列表对象。

```python
b.append(3)
print(a)  # [1, 2, 3]
```

这里修改的是共享的列表对象。

```python
b = [9]
print(a)  # [1, 2, 3]
```

这里是让 `b` 重新绑定到新对象，没有修改 `a` 绑定的原列表。

### 核心区分

- 修改对象：对象内容发生变化，其他指向同一对象的名称可以观察到。
- 重新绑定：某个名称改为指向另一对象，不会自动改变其他名称的绑定。

## 2. `is` 与 `==`

- `is`：比较对象身份，即是否为同一个对象。
- `==`：比较相等性，通常调用 `__eq__()`。

```python
a = [1, 2]
b = [1, 2]

print(a == b)  # True
print(a is b)  # False
```

判断单例对象 `None`：

```python
if value is None:
    ...
```

不要用 `is` 判断整数或字符串的值是否相等。缓存/驻留属于实现现象，不能作为值相等依据。

## 3. Python 参数传递

常见准确表述是“对象引用传递”或“按共享对象传递”。函数参数是局部名称，它会绑定到调用方传入的对象。

```python
def mutate(items):
    items.append(1)  # 修改原对象

def rebind(items):
    items = [9]      # 只改变局部名称绑定
```

不要简单回答“值传递”或“引用传递”而不解释行为。

## 4. 可变默认参数

默认参数在函数定义执行时求值一次，而不是每次调用重新求值。

```python
def add(value, items=[]):
    items.append(value)
    return items

print(add(1))  # [1]
print(add(2))  # [1, 2]
```

正确写法：

```python
def add(value, items=None):
    if items is None:
        items = []
    items.append(value)
    return items
```

`None` 在这里是哨兵值，表示调用方没有提供列表，因此函数内部创建新列表。

## 易错点

1. 错误：“每次赋值都会新分配内存。”
   - 纠正：右侧对象已存在时，可能只是建立新绑定。
2. 错误：“`is` 就是比较值所在的内存地址。”
   - 纠正：语言语义是比较对象身份。
3. 错误：“默认参数是局部变量，所以每次调用都新建。”
   - 纠正：默认值只在定义阶段求值一次。
4. 错误：“函数修改参数等于修改调用方变量。”
   - 纠正：要区分修改共享对象和重新绑定局部参数。

## 面试表达

Python 变量本质是与对象建立绑定的名称。多个变量可以绑定到同一个可变对象，所以修改对象可能被其他变量观察到；重新赋值只改变当前名称的绑定。`is` 比较对象身份，`==` 比较相等性。函数默认参数在定义阶段求值，因此可变默认参数会跨调用共享状态，通常应使用 `None` 作为哨兵值。

## AI 应用开发关联

- 可变默认参数可能造成不同 API 请求之间共享消息列表或配置，形成状态污染。
- 共享可变对象会影响会话状态、Agent state 和缓存数据隔离。
- 判断模型结果是否为空应根据语义选择 `is None`，而不是依赖真假值或对象身份缓存。
