# ```from backend.deer_flow_mcp import initialize_mcp_tools```和```from deer_flow_mcp import initialize_mcp_tools ```会初始化两个对象为什么？？
```
Python import 机制里： Python 的模块单例是按“导入名”缓存的，不是按“文件路径”缓存的。

果都能导入成功，Python 会把它们当成两个不同模块路径：
backend.deer_flow_mcp.cache
deer_flow_mcp.cache

即使指向同一份文件，也会认为是两个key
```
